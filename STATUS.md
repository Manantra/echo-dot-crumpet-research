**New (2026-10-11):** [Mutable DA1 state/source tables passed to DA2](docs/crumpet-da1-mutable-state-and-october-2026-unlock-status.md) prove multiple original DA1 writes inside the 56-byte V5 / 32-byte alternate second source, which DA1 copies into the previously verified matched ABI block. **New (2026-10-10):** [Separate first DA1 hash/data ACK and second DA2 framed SYNC](docs/da1-sha1-status-vs-da2-sync-ack.md) directly links exact original MT8167 DA1 SHA-1 compare sites and `0xC0070004` mismatch status to MTKClient `send_data` success==0 branch; the familiar `Upload data was accepted...` log occurs only before the **second** DA2 status read. **New (2026-10-10):** [DA1 actually constructs the DA2 runtime argument block](docs/mt8167-da1-runtime-parameter-block-handoff.md) with 8B header and 24+56B (V5) / 24+32B (AllInOne) copied contents, passes buffer address in `R0` to a stack-derived indirect BLX.
